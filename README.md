### `02. ThreatLens AI`

> A full-stack scam-detection platform combining machine learning, URL risk analysis and a browser extension.

**Stack:** `React` `Vite` `Tailwind CSS` `Django REST Framework` `Python` `scikit-learn` `Supabase`

**Highlights**
- Multiclass scam-message classification using TF-IDF + LinearSVC
- Confidence scoring with calibrated predictions
- Rule-based URL risk analysis
- Decision engine combining message + URL signals
- Interactive threat analytics dashboard
- Supabase authentication
- Chrome Extension with Manifest V3
- REST API for low-latency scanning

**→ [View Repository](https://github.com/Harshh1143/ThreatLens-AI)**
