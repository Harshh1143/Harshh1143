### 💰 &nbsp;Finvest — Your Financial Buddy

> A personal finance platform that tracks net worth, investments, budgets, savings goals and loan EMIs in one dashboard.

`React 19` · `Vite` · `Tailwind CSS` · `Node.js` · `Express` · `MongoDB` · `JWT`

- Net-worth dashboard pulling together spending, investments and liabilities
- Investment tracking with live profit/loss calculation
- Budget thresholds that trigger spending alerts
- Loan and EMI planning with amortisation breakdown
- JWT authentication with hashed credentials
- Chart-driven, fully responsive interface

**[→ Explore the repository](https://github.com/Harshh1143/Finvest---Your-Financial-Buddy)**

<br/>

### 🛡️ &nbsp;ThreatLens AI

> A scam-detection platform that scores suspicious messages and URLs, wrapped in a Chrome extension.

`React` · `Django REST Framework` · `Python` · `scikit-learn` · `Supabase` · `Manifest V3`

- Multiclass scam classification using TF-IDF + LinearSVC
- Calibrated confidence scores instead of bare labels
- Rule-based URL risk analysis layered on top of the model
- Decision engine that fuses message and URL signals
- Threat analytics dashboard with Supabase auth
- Low-latency REST API serving the browser extension

**[→ Explore the repository](https://github.com/Harshh1143/ThreatLens-AI)**
